# Majority Element II

**Source:** LeetCode #229 — https://leetcode.com/problems/majority-element-ii/

## Problem Statement

Given an integer array `nums` of size `n`, find all elements that appear more than `⌊n / 3⌋` times.

## Example

**Input:** nums = [3, 2, 3]
**Output:** [3]

**Input:** nums = [1, 1, 1, 3, 3, 2, 2, 2]
**Output:** [1, 2]

## Constraints

- 1 <= nums.length <= 5 * 10^4
- -10^9 <= nums[i] <= 10^9

## Follow-up

Could you solve the problem in O(n) time and O(1) space?
