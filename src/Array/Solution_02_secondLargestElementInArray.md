# Second Largest Element in an Array (Without Sorting)

**Source:** takeUforward

## Problem Statement

Given an array of integers `nums`, find the second largest distinct element in the array without sorting it.

If no second largest element exists (for example, the array has fewer than 2 distinct elements), return `-1`.

## Example

**Input:** nums = [8, 10, 5, 7, 9]
**Output:** 9
**Explanation:** The largest element is 10, and the second largest distinct element is 9.

**Input:** nums = [1, 1, 1]
**Output:** -1
**Explanation:** All elements are the same, so there is no second largest distinct element.

## Constraints

- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9
- The array may contain duplicates.
