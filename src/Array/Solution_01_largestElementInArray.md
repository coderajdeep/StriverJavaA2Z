# Largest Element in an Array

**Source:** takeUforward

## Problem Statement

Given an array of integers `nums`, find and return the largest element present in the array.

You must solve this by scanning the array (no built-in sort/max utilities expected) in a single pass.

## Example

**Input:** nums = [2, 5, 1, 3, 0]
**Output:** 5
**Explanation:** 5 is the largest element in the array.

**Input:** nums = [8, 10, 5, 7, 9]
**Output:** 10
**Explanation:** 10 is the largest element in the array.

## Constraints

- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9
