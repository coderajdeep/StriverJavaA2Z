# Pascal's Triangle (Print the Entire Triangle)

**Source:** takeUforward

## Problem Statement

Given an integer `numRows`, generate the first `numRows` rows of Pascal's triangle and return them as a list of lists.

In Pascal's triangle, each number is the sum of the two numbers directly above it (with the boundary numbers of each row always being 1).

This is the takeUforward "print Pascal's Triangle" variant that builds the whole triangle row by row (as opposed to only finding a single element at row R, column C, or only printing a single row).

## Example

**Input:** numRows = 5
**Output:** [[1], [1,1], [1,2,1], [1,3,3,1], [1,4,6,4,1]]

**Input:** numRows = 1
**Output:** [[1]]

## Constraints

- 1 <= numRows <= 30
