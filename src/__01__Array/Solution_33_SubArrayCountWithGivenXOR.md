# Count Subarrays with XOR Equal to K

**Source:** takeUforward

## Problem Statement

Given an array of integers `nums` and an integer `k`, count the total number of contiguous subarrays whose XOR of all elements equals `k`.

## Example

**Input:** nums = [4, 2, 2, 6, 4], k = 6
**Output:** 4
**Explanation:** There are multiple contiguous subarrays whose elements XOR together to 6.

**Input:** nums = [5, 6, 7, 8, 9], k = 5
**Output:** 2

## Constraints

- 1 <= nums.length <= 10^5
- 0 <= nums[i] <= 10^9
- 0 <= k <= 10^9
