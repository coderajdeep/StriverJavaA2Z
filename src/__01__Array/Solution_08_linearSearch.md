# Linear Search

**Source:** takeUforward

## Problem Statement

Given an array of integers `nums` and an integer `target`, return the index of the first occurrence of `target` in `nums` by scanning the array from left to right. If `target` is not present in the array, return `-1`.

## Example

**Input:** nums = [3, 4, 1, 7, 9], target = 7
**Output:** 3
**Explanation:** nums[3] = 7, so index 3 is returned.

**Input:** nums = [1, 2, 3], target = 5
**Output:** -1
**Explanation:** 5 does not exist in nums, so -1 is returned.

## Constraints

- 1 <= nums.length <= 10^5
- -10^9 <= nums[i], target <= 10^9
