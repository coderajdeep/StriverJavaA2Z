# Generate Parentheses

**Source:** LeetCode #22 — Generate Parentheses (inferred; filename has no LeetCode number, but the code is the canonical solution to this problem)

## Problem Statement

Given `n` pairs of parentheses, write a function to generate all combinations of well-formed (balanced) parentheses.

## Example

**Input:** n = 3
**Output:** ["((()))","(()())","(())()","()(())","()()()"]

**Input:** n = 1
**Output:** ["()"]

## Constraints

- `1 <= n <= 8`
