# Longest Common Substring

**Source:** takeUforward / GFG

## Problem Statement

Given two strings `s1` (of length `n`) and `s2` (of length `m`), find the length of the longest common substring — a contiguous sequence of characters that appears in both strings.

Unlike a subsequence, a substring must occupy consecutive positions within each original string.

## Example

**Input:** s1 = "abcjklp", s2 = "acjkp"
**Output:** 3
**Explanation:** The longest common substring is "cjk", which has a length of 3.

**Input:** s1 = "abcde", s2 = "abfce"
**Output:** 2
**Explanation:** The longest common substring is "ab", which has a length of 2.

## Constraints

- 1 <= n, m <= 1000
- s1 and s2 consist of lowercase English letters.
